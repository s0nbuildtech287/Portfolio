# 🌐 MySocial - Personal Command Center

MySocial là một trung tâm quản lý tài khoản cá nhân cao cấp, bảo mật và trực quan. Ứng dụng được thiết kế nhằm giúp người dùng lưu trữ, phân loại và truy cập nhanh các tài khoản mạng xã hội, cổng thông tin trường học, lập trình và công việc của mình một cách có tổ chức và an toàn nhất.

---

## ✨ Tính năng nổi bật

### 1. Hệ thống Điều hướng Đa dạng & Khoa học (Command Center Navigation)
*   All Accounts: Quản lý toàn bộ các thẻ tài khoản mạng xã hội cá nhân.
*   Statistics (Thống kê): Giao diện biểu đồ phân tích tần suất, độ bảo mật và xu hướng sử dụng tài khoản (Sắp ra mắt).
*   Business (Kinh doanh): Khu vực dành riêng cho các tài khoản phục vụ kinh doanh và đối tác kinh tế (Sắp ra mắt).
*   Startup (Khởi nghiệp): Trạm làm việc (Coding & Projects Hub) gom nhóm dự án phát triển cá nhân (Sắp ra mắt).
*   Categories (Danh mục tùy biến): Phân loại tài khoản theo mục cha-con linh hoạt (Mạng xã hội, Dev & Cloud, Học tập, Giải trí...). Giao diện điều hướng cho phép ẩn/hiện danh sách danh mục cùng nút tạo nhanh tiện lợi.

### 2. Bảo mật Tuyệt đối với Khóa Hình vẽ (Pattern Lock Guard)
*   Mở khóa bảo mật: Người dùng chỉ có thể xem mật khẩu hoặc sao chép mật khẩu bằng cách vẽ đúng hình khóa bảo mật (Pattern Lock).
*   Bảo mật hai lớp khi chỉnh sửa: Ngay cả trong modal chỉnh sửa thông tin tài khoản (Edit Account), tính năng xem mật khẩu cũng được bảo vệ nghiêm ngặt bằng khóa hình vẽ.
*   Mã hóa lưu trữ: Mật khẩu được bảo vệ khỏi việc hiển thị vô tình trên màn hình.

### 3. Tự động hóa Dữ liệu cục bộ (Local Sync)
*   Tự động cập nhật: Mọi chỉnh sửa, thêm mới, xóa tài khoản hay danh mục đều được cập nhật tự động vào localStorage của trình duyệt.
*   Mẫu dữ liệu phong phú (Initial MockData): Hệ thống tích hợp sẵn các bộ tài khoản mẫu phổ biến nhất từ GitHub, Microsoft, Shopee, Spotify, SoundCloud, và đặc biệt là hệ thống cổng thông tin trường đại học TLU (Đại học Thủy Lợi) với logo nhận diện đặc trưng.

### 4. Sao lưu & Phục hồi thông minh (Backup & Restore JSON)
*   Xuất dữ liệu toàn bộ tài khoản và danh mục ra file cấu trúc .json chỉ với 1 click.
*   Nhập (Import) file JSON để phục hồi hoặc đồng bộ sang máy khác khi triển khai (Deploy) thực tế mà không sợ mất dữ liệu.

## 🛠️ Công nghệ sử dụng

*   Core: React 18, TypeScript
*   Build Tool: Vite (Hot Module Replacement cực nhanh)
*   Styling: Modern CSS kết hợp hiệu ứng Glassmorphism (Kính mờ), chuyển động mượt mà và giao diện tối (Dark Mode) thời thượng.
*   Icons: Lucide React & Google Material Symbols.

## 🚀 Hướng dẫn khởi chạy dưới Local

### 1. Cài đặt các thư viện phụ thuộc
Mở Terminal tại thư mục dự án và chạy lệnh cài đặt:
```bash
npm install
```

### 2. Chạy ứng dụng ở môi trường Development
Khởi động máy chủ phát triển local:
```bash
npm run dev
```
Ứng dụng sẽ khả dụng tại địa chỉ mặc định: http://localhost:5173.

### 3. Build Production
Kiểm tra kiểu dữ liệu TypeScript và build tối ưu hóa cho sản xuất:
```bash
npm run build
```
Thư mục dist sau khi build xong sẽ sẵn sàng để đẩy lên các nền tảng hosting như Vercel, Netlify hoặc GitHub Pages.

## 🔒 Khóa Hình vẽ Mặc định (Default Pattern Lock)
*   Hình vẽ mặc định để xem mật khẩu là: Hình chữ L (nối các điểm theo thứ tự 0 -> 3 -> 6 -> 7 -> 8).
*   Bạn có thể thay đổi hình vẽ này trong mục Settings (Cài đặt) ở góc dưới sidebar.
